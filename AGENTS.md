# AGENTS

## Build And Run

- Use `./build.sh` from the repository root to build the app.
- Use `./launch.sh` from the repository root to start the app. This is a graphical app, so launching and interactive verification should be done by the user in a desktop session.

## Verification

- After making code changes, run `./build.sh` from the repository root to verify the app still builds.
- If the change affects runtime behavior or UI flow, the user should run `./launch.sh` and confirm the affected behavior manually in the app.
